# The Cryptographic Vault 🔐

A two-player code-breaking game built in C.

## About

The Cryptographic Vault is a two-player game where Player 1 creates a secret 5-digit code using digits from 1–9, and Player 2 attempts to recreate the code.

The game includes digit confirmation, input validation, final code confirmation, score tracking, and replay functionality.
The game is best played in windowed mode.

## Features

* Two-player gameplay
* 5-digit secret code
* Digit confirmation
* Guess confirmation
* Input validation
* Score tracking
* Replay functionality

## Concepts Used

* `switch-case`
* `if-else`
* `for` loops
* `while` loops
* `do-while` loops
* Variables and data types
* Input validation
* Basic arithmetic
* Game logic

## Built With
